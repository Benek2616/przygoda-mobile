# 🏰 Tajemnica Starego Zamku

Fajna, krótka przygodówka na telefon z wyborami, ekwipunkiem i kilkoma zakończeniami.

## O grze
Jesteś poszukiwaczem przygód, który trafia do starego zamku w poszukiwaniu magicznego amuletu. Twoje decyzje mają znaczenie – możesz znaleźć skarb, uciec z życiem, dogadać się ze strażnikiem... albo skończyć źle.

### Funkcje
- Interaktywna historia z wieloma ścieżkami
- System ekwipunku (latarnia, klucz, olej...)
- 4 różne zakończenia
- Działa świetnie na telefonie (duże przyciski, touch-friendly)
- Czysty HTML + JS – zero instalacji

## Jak włączyć GitHub Pages (stały ładny link)
1. Wejdź w repozytorium → **Settings** → **Pages**
2. Source → **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save
5. Po chwili gra będzie pod: https://benek2616.github.io/przygoda-mobile/
